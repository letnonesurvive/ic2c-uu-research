# Машина v2 (призрачная цель + расход UU) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Исследование по призрачной цели: машина забирает UU-материю по рецепту, тратит EU, выдаёт результат крафта и открывает рецепт; иридий — в системе; вёдра и образец убраны.

**Architecture:** UU-рецепт переопределяется как «рецепт IC2, все ингредиенты которого — UU-материя» (без требования hidden → иридий входит). Индекс кэширует `Item → рецепт` на `RecipeManager`. Машина хранит цель в отдельном `SimpleInventory(1)` (не выпадает, недоступна автоматике), показывает её через IC2 `GhostSlot` + `FilterComponent`, копит UU во внутреннем запасе (рецепт элитр — 112 > 64 в слоте) и по окончании кладёт результат крафта в выход.

**Tech Stack:** Forge 1.19.2-43.5.0, IC2 Classic 2.1.3.4 (GhostSlot, FilterComponent, SimpleInventory, BaseMachineTileEntity), JUnit 5.

**Spec:** `docs/superpowers/specs/2026-09-27-uu-research-design.md` — раздел «Машина v2 … (дизайн 2026-09-29)».

## Global Constraints

- Слоты основного инвентаря не меняются: 0 батарея, 1 вход (теперь **только UU-материя**), 2 выход, 3–6 апгрейды; цель — отдельный `SimpleInventory(1)`
- UU на крафт = `max(1, round(milliUU × resultCount / 1000))`; `milliUU` из `UURecipeIndex.milliUUCost`
- Изученная цель не обрабатывается; не-UU цель игнорируется
- Выход: пусто или тот же предмет с местом под весь результат, иначе ждать
- Запас UU (`storedUU`) сохраняется в NBT и выпадает при поломке стаками UU-материи
- Иридий в системе (скрыт в JEI и заблокирован до изучения); `ResearchTarget` (вёдра) удалить
- Энергия/время: как раньше (`ResearchCost.totalEu(milliUU, euPerUU)`, 32 EU/t)
- `JAVA_HOME=/opt/homebrew/opt/openjdk@17`; комментарии в коде на английском; коммит — после проверки пользователем

## Review Focus

1. **Дюп через призрак:** цель не должна выпадать при поломке и не должна извлекаться воронками — отдельный `SimpleInventory`, не в `addDrops`, без доступа в `InventoryHandler`.
2. **Потеря UU:** запас выпадает при поломке; смена цели не сжигает запас.
3. **Нехватка места в выходе:** машина ждёт, UU не списывается, результат не теряется.
4. **Цель изучили командой во время работы:** обработка останавливается, UU из запаса не списывается.
5. **Производительность тика:** поиск рецепта цели — через кэш индекса, без полного перебора рецептов каждый тик.

```java
    private static final IdentityCache<RecipeManager, Map<Item, CraftingRecipe>> BY_OUTPUT = new IdentityCache<>();

    /** An IC2 recipe made only of UU-Matter: the UU shapes, including the ones IC2 shows (iridium ore). */
    public static boolean isUURecipe(CraftingRecipe recipe) {
        if (!(recipe instanceof RecipeIC2Base)) {
            return false;
        }
        ItemStack uuMatter = new ItemStack(IC2Items.UUMATTER);
        boolean any = false;
        for (Ingredient ingredient : recipe.getIngredients()) {
            if (ingredient.isEmpty()) {
                continue;
            }
            if (!ingredient.test(uuMatter)) {
                return false;
            }
            any = true;
        }
        return any;
    }

    @Nullable
    public static CraftingRecipe recipeFor(RecipeManager manager, Item item) {
        return BY_OUTPUT.get(manager, UURecipeIndex::collectRecipes).get(item);
    }

    public static boolean hasUURecipe(RecipeManager manager, Item item) {
        return recipeFor(manager, item) != null;
    }

    private static Map<Item, CraftingRecipe> collectRecipes(RecipeManager manager) {
        Map<Item, CraftingRecipe> recipes = new HashMap<>();
        for (CraftingRecipe recipe : all(manager)) {
            recipes.putIfAbsent(recipe.getResultItem().getItem(), recipe);
        }
        return recipes;
    }
```
